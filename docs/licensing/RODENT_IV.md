# Rodent IV local integration

The personality opponent uses Rodent IV 0.33, built from upstream
revision `e8d84c8c8c189a1cf4eb27c578fc573af3b916d2`.

- Source: https://github.com/nescitus/rodent-iv/tree/e8d84c8c8c189a1cf4eb27c578fc573af3b916d2
- Archive SHA-256: `5d35c65bfccd58fe74a73b58434ec1542f4aabc45b343163b277870c681f7773`
- Upstream license: GPL version 3 or later, as stated in the C++ source headers.
- Authors credited by upstream include Pawel Koziol, Bernhard C. Maerz and
  Pablo Vazquez (Sungorus).
- Build helper: `tools/install_rodent.py`; compiler and arguments are recorded
  in `engines/rodent-iv/manifest.json`.

The helper builds unmodified C++ source using MinGW-w64, with generic x64
instructions and static compiler runtimes. It installs the complete source
archive, upstream LICENSE and README, and its own build script beside the binary.
The application communicates with the separate executable through UCI.

The installed `personalities/basic.ini` is generated by the helper to expose
`PersonalityFile`, keep native Elo limiting enabled and use personality opening
books. Individual personality files are copied unchanged from upstream.

Opening books come from the same pinned repository. Its `books/#readme.txt`
and per-directory attribution files are retained. The player-book attribution
file credits Pawel Hase, the Robinson jeux collection, Brendan J. Norman and
Pawel Koziol. The two default books come from the upstream `exe` directory.

The 1.6.4 frozen build includes the complete `engines/rodent-iv` directory alongside
Stockfish and Fairy-Stockfish. Build preparation verifies the source revision and
all manifest file hashes, and payload staging verifies the copied directory again.
Previously produced installers and historical inventories remain unchanged.
