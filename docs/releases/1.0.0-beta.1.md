# OTBMaster3D 1.0.0 Beta 1

The first official free, open-source beta. Tag: `v1.0.0-beta.1`.
Earlier 7.x/8.x tags are development milestones, not the public version sequence.

## Included

- 2D and 3D boards, multiple piece sets, board materials and interface themes.
- Click/drag moves, promotion choices, selection/hover and last-move highlights.
- PGN/FEN import/export, history navigation and automatic session recovery.
- Automatic and over-the-board clocks.
- Stockfish 19 setup with verified downloads and remembered engine selection.
- Three CC0 opening repertoires, approximate Elo control and playing styles.
- Numbered engine lines with start/stop analysis, plus instant position evaluation.
- Optional evaluation beside MOVE LIST, remembered across launches.
- New Game requests wait for engine startup/search instead of losing the first click.

## Install and run

Use Windows x64, Python 3.13 with Tk support, and an OpenGL 2.1 graphics driver.
Follow the commands in the root README. Stockfish is a separate official download
installed by `tools/install_stockfish.py`; its executable is not committed to Git.

This is a source beta. The Windows installer remains paused and is not included.
The icon and packaging scaffolding are retained for a later binary release.

## Known limitations

- The instant position score is a heuristic, not tactical search.
- Elo targets are approximate; style preferences and opening books affect strength.
- The live rules backend remains python-chess; the independent core is experimental.
- PGN/FEN files are supported; there is no built-in saved-game library.
- Source-run settings and sessions stay in the checkout. Back up your PGN files.
