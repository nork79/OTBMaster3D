# OTBMaster3D 1.6.8

Published on 2026-10-15. All eight release assets were downloaded from their
public GitHub URLs and verified against the prepared SHA-256 checksums.

## Changes

- Correct classic board face winding and stabilize the frame appearance on flip.
- Improve captured-piece colours and rendering, retain compact matching shapes,
  and keep equal capture areas with a stationary centered divider.
- Match game status text to the time-control and opening descriptions.
- Add installer version arguments, progress/error messages and dry-run support.
- Fix Visual Studio PATH handling in the native GLFW build.

## Source pairing

The build records base commit `c62a117ec14f61b2c4f9a41b5171fa90e382c115`
and uncommitted changes. That base commit alone does not reproduce this release.
All files in the frozen source snapshot matched the workspace before release
documentation was prepared. The subsequent release commit/tag also includes
publication documentation; the named application archive is the exact build
snapshot, not GitHub's automatically generated tag ZIP.

The original source ZIP and build-info.json remain unchanged, including their
historical publication-status fields. This release document and the pairing
manifest describe the separately prepared source distribution. The application
archive alone does not include all dependency source: download both archives.
Dependency inputs are hash-checked against the frozen source inventory; Rodent
source and build files come from the same frozen payload.

The dependency archive is reused from 1.6.5: all 70 dependency source files
and five Rodent source/build files are byte-for-byte identical to those prepared
for 1.6.8. Its inventory differs only in the release version label, and its
release notes describe 1.6.5; use this document for 1.6.8.

## Build from the archives

1. Extract the application ZIP and enter its `OTBMaster3D` directory.
2. Extract the dependency ZIP. Copy `sources` to
   `release-materials/1.4.0-beta.2/sources` under the application directory.
   Retain `rodent-iv/` for the matching engine source and build recipe.
3. Follow the archived README and `docs/windows-installer.md` for Python 3.13,
   pinned dependencies, MSVC/Windows SDK, MinGW-w64 and Inno Setup.
4. See `docs/licensing/BUILD_AND_REPLACE.md` for library replacement instructions.

## Validation and requirements

The frozen 1.6.8 application passed its packaged smoke test: native OpenGL,
engine evaluation, all three opening books, PGN roundtrip, audio API and clean
shutdown. Audibility was not verified. The payload also passed the standalone
Microsoft-binary exclusion check. All 288 source tests passed across the 283-test main run and a separate
five-test native-access rerun of the Tcl/Tk piece-set class, whose initial
setup was blocked in the sandbox.
Clean Windows installation, upgrade and uninstall validation remain pending.
Windows 10 or later, x64 hardware and an OpenGL 2.1-capable driver are required.
Microsoft Visual C++ x64 Redistributable 14.44.35211.0 or newer is a separate
prerequisite checked by Setup. Python is bundled. The installer is unsigned.
No clean-machine or bit-for-bit reproducibility claim is made.
