# OTBMaster3D 1.6.9

Published on 2026-10-18.

## Changes

- Evaluate each new position with a two-second background Stockfish search,
  independently of the opponent engine and analysis window. Discard results
  from previous positions.
- Update the move-list score silently, retaining the last number while the next
  search runs. Match evaluation and material-count typography to Move List.
- Split Engine Analysis into equal, resizable panes: retained best-three moves
  above and current dynamic analysis below. Both panes support move previews.
- Retain each move's best score found in the upper pane, ranking for the side
  to move. Later worse evaluations appear in live analysis without lowering
  the retained score. Clear retained variations when the position changes.

## Build from the archives

1. Extract the application ZIP and enter its `OTBMaster3D` directory.
2. Extract the dependency ZIP and copy `sources` to
   `release-materials/1.4.0-beta.2/sources` under that directory. Retain
   `rodent-iv/` for the engine source and build recipe.
3. Follow the archived README and `docs/windows-installer.md` for Python 3.13,
   pinned dependencies, MSVC/Windows SDK, MinGW-w64 and Inno Setup.
4. See `docs/licensing/BUILD_AND_REPLACE.md` for library replacement instructions.

## Validation and requirements

The frozen application passed its packaged smoke test, covering native OpenGL,
engine analysis, opening books, PGN roundtrip, audio API and clean shutdown.
Audibility was not verified. The payload passed the standalone Microsoft-binary
exclusion check. All 299 source tests passed across the 294-test main run and a
five-test native-access rerun of the legacy piece-set class. Its initial setup
failed because Tcl/Tk could not initialize in the sandbox. Both run results are
recorded in `validation-1.6.9.json`.

Clean Windows installation, upgrade and uninstall validation remain pending.
Windows 10 or later, x64 hardware and an OpenGL 2.1-capable driver are required.
Microsoft Visual C++ x64 Redistributable 14.44.35211.0 or newer is a separate
prerequisite checked by Setup. Python is bundled; the installer is unsigned.
No clean-machine or bit-for-bit reproducibility claim is made.
