# OTBMaster3D 1.6.0 source preparation (unpublished)

**Prepared locally; not published.** On 2026-09-30 the maintainer deferred choosing
a public hosting location. The existing GitHub repository is private. All links
below are proposed locations and have not been verified as public downloads.
No repository visibility, tag or release was changed.

This retained source snapshot corresponds to the local Windows installer built from
commit `87d30dc4d0c0f118a20a25170e826be52347d8a0`. The installer is not published
here; clean Windows installation testing remains pending.

Current `main` includes later changes, including optional Rodent IV opponents.
These prepared archives do not represent current `main` or include that later
integration. The application version remains 1.6.0.

The application ZIP is byte-for-byte identical to the source ZIP embedded in the
installer. Its original documentation records the decisions at build time.
Subsequently, the maintainer withdrew the itch.io plan and removed the speculative
embedded Microsoft code concern as a release blocker. These changes do not alter
the archived application code. Original `build-info.json` is retained as build
evidence; its publication-pending text predates this source preparation.

The dependency ZIP contains 70 hash-pinned archives and source inputs, including
Qt/PySide/Shiboken, CPython, python-chess, Stockfish 19 and its network,
Fairy-Stockfish 14, native dependencies and original artwork. Each input is listed
with its SHA-256 in `source-inventory.json` inside the dependency ZIP.

## Build and modification instructions

1. Extract the application ZIP and open its `OTBMaster3D` directory.
2. Extract the dependency ZIP. For the archived build scripts, put its `sources`
   directory under `release-materials/1.4.0-beta.2/` in the application checkout.
   That directory name is an existing cache convention, not the application version.
3. Follow `README.md` and `docs/windows-installer.md` for Python 3.13 x64,
   dependencies, MSVC/Windows SDK and Inno Setup. The archived installer build
   script and spec are the ones used for the paired build.
4. Follow the build instructions in the individual upstream source archives to
   modify dependencies. `docs/licensing/BUILD_AND_REPLACE.md` describes compatible
   shared Qt/PySide/Shiboken replacement. No signature or content lock prevents it.

The actual installer requires a separately installed Microsoft x64 runtime;
it does not bundle or download Microsoft's redistributable. Earlier archived
documents describing a bundled prerequisite are superseded by the build scripts
and `docs/licensing/MICROSOFT_RUNTIME_REMEDIATION.md`.

When published, these source downloads must be free and require no purchase.
GPL rights and the original third-party licences remain unchanged. A successful development-host smoke test
does not establish clean Windows installation compatibility.
