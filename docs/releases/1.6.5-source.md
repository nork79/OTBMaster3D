# OTBMaster3D 1.6.5

Public release: 2026-10-05. This release publishes the existing 1.6.5 Windows
build from clean commit `4e1ba003c85bf10d3c238aa4ef791d081af55209`.

## Changes

- Reset the board to the last opened bookmark, or the initial position if it is
  unavailable, with both clocks reset and paused.
- Apply saved clock settings immediately, resetting and pausing both clocks.
- Include Rodent IV personalities and repertoire books alongside Stockfish 19,
  Fairy-Stockfish 14 and the three application opening books.

## Build from the archives

1. Extract the application ZIP and enter its `OTBMaster3D` directory.
2. Extract the dependency ZIP. Copy its `sources` directory to
   `release-materials/1.4.0-beta.2/sources` in the application directory. This older
   directory name is the build scripts' cache convention. Retain `rodent-iv/` for
   its matching engine source and build recipe.
3. Follow the archived README and `docs/windows-installer.md`: Python 3.13 x64,
   pinned dependencies, MSVC/Windows SDK, MinGW-w64 and Inno Setup are required.
4. Follow `docs/licensing/BUILD_AND_REPLACE.md` and each dependency's build
   instructions for compatible library replacement.

The unchanged application snapshot and `build-info.json` retain pre-publication
notices. This document and the release pairing manifest describe publication;
historical reports apply only to their named builds. No binary or embedded source
was changed to update those historical notices.

## Requirements and validation

Windows 10 or later, x64 hardware and an OpenGL 2.1-capable driver are required.
Install Microsoft Visual C++ x64 Redistributable 14.44.35211.0 or newer separately;
Setup checks this prerequisite. Python is bundled. The installer is unsigned.

The recorded build verification reports a passing packaged smoke test, 1,323
verified application file hashes and 268 passing tests. All eight piece-set tests
passed separately with desktop access after a sandbox Tcl setup error.
Clean Windows installation, upgrade and uninstall testing remain pending.
No clean-machine or bit-for-bit reproducibility claim is made.
