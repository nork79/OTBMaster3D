# OTBMaster3D 1.2.0 Beta 1

Source prerelease: `v1.2.0-beta.1`. No Windows installer is attached.

## Changes

- Add Maia CPU support and difficulty presets from beginner practice through full-strength Stockfish, including new Maia 1300 and 1500 levels.
- Remember difficulty and analysis settings; open Custom settings directly from its menu action.
- Add Setup Position with live FEN paste, starting/empty boards, Textbook pieces, click-to-pick-up/drop with replacement, right-click colour toggle and middle-click erase. Setup games start at move 1.
- Add a clickable move-by-move static evaluation graph with position review.
- Add eight sound profiles and No sounds, remembered between launches.
- Apply clock changes immediately before the first move and allow individual clock edits after New Game.
- Center and fit Reset View to the viewport at a 40-degree viewing angle.
- Set fresh-install defaults to Dark, Tournament Wood, Tournament Staunton, solid background, Textbook 2D pieces, full engine strength, analysis off and Bullet 2+1.
- Update Windows installer build support; the published beta remains source-only.

## Run

Follow the root README using Windows x64, Python 3.13 with Tk support, and OpenGL 2.1.
Install dependencies and run `tools/install_stockfish.py` and `tools/install_maia.py` for the optional engines, then start `main.py`. Downloaded engines and personal game/configuration files are not included in Git.

## Notes

Difficulty numbers are approximate practice labels, not certified ratings. Beginner levels add random legal mistakes to Maia 1100. Maia model training ratings are not measured playing Elo. Static evaluation is a heuristic, not tactical engine analysis.

Application source is GPL-3.0-or-later. Third-party components retain their own terms; see THIRD_PARTY_NOTICES.md and third_party_bom.json.

## Validation

Desktop UI and real Stockfish/Maia integration checks passed locally on Python 3.14. The experimental-core tests require the pinned cozy-chess dependency, whose current bindings support up to Python 3.13; the complete non-graphical checks run in Windows CI on the supported Python 3.13 runtime. Python syntax compilation and whitespace checks passed.
