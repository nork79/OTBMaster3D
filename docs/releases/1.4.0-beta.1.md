# OTBMaster3D 1.4.0-beta.1

**Beta / pre-release, distributed only within the private repository.**

- Customizable interactive 3D and 2D chess boards, pieces and interface themes.
- Chess clocks, takeback, resign/draw and pause-on-switch playing sides.
- Stockfish analysis and Maia-based difficulty resources.
- Hierarchical bookmarks, nested folders, position restoration and persistent preferences.
- Eight sound profiles, PGN/FEN workflows and session recovery.
- Windows installer with bundled runtime, engines, assets and opening books.

Validation: 166 automated tests passed during stabilization; packaged smoke testing
verifies launch, native rendering, Stockfish analysis and all three opening books.
No application functionality changed during private release preparation.

The installer is unsigned; Windows may show a security/reputation warning.
Clean-machine and multi-monitor/DPI verification remain manual. Review the
[licence gaps](../private-release-review.md) before any future public distribution.
