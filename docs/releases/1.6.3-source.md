## Build from these sources

1. Extract the application ZIP and enter its OTBMaster3D directory.
2. Extract the dependency ZIP and copy its sources directory to
   release-materials/1.4.0-beta.2/sources in that application directory. The old
   directory name is the build scripts' cache convention.
3. Follow README.md and docs/windows-installer.md for Python 3.13 x64,
   dependencies, MSVC/Windows SDK and Inno Setup. Use the build scripts from
   the archived application.
4. Follow each dependency's retained build instructions and
   docs/licensing/BUILD_AND_REPLACE.md for compatible shared-library replacement.

The installer requires the separately installed Microsoft x64 runtime described
in docs/licensing/MICROSOFT_RUNTIME_REMEDIATION.md; it does not bundle or download it.
The historical source preparation helper in the application archive contains
older release defaults. The two supplied archives already contain the prepared
source materials; running that helper is not required to build the application.
