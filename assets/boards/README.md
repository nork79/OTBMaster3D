The bundled files are the original colour maps from the 1K JPG archives.
`sources.json` records download URLs, original archive names and SHA-256 hashes.
Only colour maps are used; this renderer does not implement the source materials'
full PBR shading. Runtime luminance modulation lets the user's board colours show
through the marble veining, wood grain and fabric weave.

The rounded board profiles, slab geometry, trim and stitching are generated by
the application's own `otb_chess/graphics/board_types.py`; they are not downloaded
chessboard meshes. No network access is needed at runtime.
